# 🏢 Employee Attrition Analysis (HR Analytics)

## Project Overview
Proyek ini menganalisis faktor-faktor yang menyebabkan karyawan meninggalkan perusahaan menggunakan dataset **IBM HR Analytics**. Tujuannya adalah memberikan rekomendasi berbasis data kepada tim HR untuk meningkatkan retensi karyawan.

## Key Questions & Insights
1. **Dampak Lembur:** Karyawan yang sering lembur memiliki rasio pengunduran diri yang jauh lebih tinggi dibandingkan yang tidak lembur.
2. **Faktor Finansial:** Mayoritas karyawan yang keluar berada di kelompok pendapatan bulanan rendah ($2.500 - $6.000).
3. **Kepuasan vs Gaji:** Lingkungan kerja yang nyaman (skala 3-4) tetap berisiko kehilangan karyawan jika gaji yang ditawarkan tidak kompetitif.

## Tech Stack
- **Python** (Pandas, Matplotlib, Seaborn)
- **Google Colab**

## Recommendations
- Meninjau kembali beban kerja untuk mengurangi burnout akibat lembur.
- Melakukan adjustment gaji pada level entry/staf untuk menjaga daya saing di pasar tenaga kerja.
